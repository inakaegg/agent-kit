# 001 pair-watchプラグインへ一本化する

- 決定日: 2026-08-25（記録日: 2026-09-01。決定時にADRを残さなかったため遡って記録）
- 状態: 採用済み

## 決めたこと

kit同梱の `skills/pair/`（日本語版の2セッション用スキル）を廃止し、単体配布の [pair-watch](https://github.com/inakaegg/pair-watch) プラグインをこの仕組みの唯一の正本とする（廃止commit: 893b119）。kitの利用者もプラグインをインストールして使う。

## 理由

同じ手順の日本語版（kit側）と英語版（プラグイン側）を2か所で保守する二重管理になっていた。片方だけ更新されて乖離する事故が実際に起きており（プラグイン側READMEの出自の記述が分割前のまま残り、kit側の記述と矛盾した）、保守先を1つにする必要があった。

## 検討した代替案

- **並存の継続（日本語正本＋英語追随）**: 更新のたびに2か所の同期が必要で、乖離リスクが解消しない。却下。
- **kit側へ一本化**: kitは個人設定込みの作業キットで、単体インストールできる配布形態を持たない。外部利用者に配布できるのはプラグイン側だけ。却下。

## トレードオフ

- kitだけを導入した環境では、pair体制を使うために別途プラグインのインストールが必要になる（kit READMEに手順を記載済み）。
- スキル本文が英語になる（出力言語はタスク記述の言語に追従するため、日本語での利用は変わらない）。
